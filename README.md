# APS Voice Service

AI-powered voice answering service for APS Service — a mobile ADAS calibration company in the Florida Panhandle.

## Stack
- FastAPI
- ElevenLabs (voice clone)
- Twilio (inbound calls)
- Telegram (lead notifications)
- PM2 (process management)
